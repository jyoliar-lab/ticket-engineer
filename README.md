# ticket-engineer

ops-workflow의 **티켓(GitHub Issue)을 집행하는 엔지니어 agent의 하네스** 저장소.

- 이 저장소는 아직 **스켈레톤**이다. 하네스 설계(CLAUDE.md·agent·skill·hook)는 ops-workflow-steward의 인수인계 문서(`handover/260722-ticket-engineer-design.md`)를 받은 세션에서 진행한다.
- 이 하네스의 개정 주체는 **ops-workflow-steward(+사람)** 다. agent 자신은 자기 하네스를 고치지 않는다.
- 티켓 관련 정책 ADR이 accept되면, 이 하네스는 그 정책의 반영 여부를 steward의 `conformance` 감사로 검증받는다.
